# show-me 사용 가이드

## 지금 할 일

### 1. 설치하고 점검한다

작업 폴더(강의 자료를 둘 저장소나 폴더)에서 설치한다.

```bash
npx skills@1.7.4 add ynginkim/show-me -a claude-code -a codex
```

Claude Code에서 "강의 자료 만들어 줘"처럼 요청하면 `show-me-mode`가 시작된다. 첫 실행에서 에이전트가 `preflight.py`를 돌려 촬영 도구(playwright-core)가 없으면 설치를 물어본다. 설치는 `skills/resolve-show-me-tools/scripts/node_modules`에만 생긴다.

### 2. 처음 한 번만 답한다

에이전트는 사용자만 아는 것만 묻는다: 청중, 강의 길이, 장소·화면, 꼭 넣을 것, 자료 위치, 공개 범위. 구성·장 수·색·애니메이션은 근거를 붙여 스스로 정하고 `talk.md`에 적는다.

### 3. 결과를 리허설한다

`slides/index.html`을 발표할 컴퓨터의 브라우저로 연다.

| 키 | 동작 |
| --- | --- |
| ← → | 넘기기 |
| G | 전체 보기(누르면 그 장으로) |
| F | 전체 화면 |
| T | 구간 타이머. 예산의 85%에서 주황, 넘으면 빨강 |
| 1~9 | 탭 고르기, 녹화의 장(chapter) 고르기 |
| P / Z | 녹화 재생·멈춤 / 확대 |

에이전트는 1920×1080 스크린샷과 자동 검사로만 확인했다. 발표 화면에서 맨 뒷줄 글자 크기, 영상 소리, 실제로 말하는 시간은 리허설로 확인한다.

### 4. 고칠 것을 말한다

"2구간을 3분 줄여 줘", "6번 장 캡처를 새 걸로", "이 문장 더 쉽게"처럼 말하면 `revise-deck`이 수정 전 촬영본을 남기고, 고친 뒤 장마다 비교해 바뀐 장을 보고한다.

### 5. 영상 프로젝트와 함께 쓴다

Lightplay로 만든 오프닝 영상이 있으면 그 프로젝트 경로를 알려 준다. 에이전트가 `out/`의 납품 영상·포스터·자막과 `timeline.json`의 장면 시각을 덱으로 복사하고 출처를 `slides/media/media.json`에 남긴다. 영상 프로젝트 파일은 바꾸지 않는다. 영상을 다시 렌더했으면 "영상 바뀌었어"라고만 하면 해시를 비교해 다시 가져온다.

## 덱 폴더를 직접 만질 때

- 슬라이드를 고치는 파일은 `slides/index.html` 하나다. 빌드 단계가 없다.
- 색과 글꼴은 `slides/deck.css`의 토큰(`--accent`, `--accent2`, `--night` 등)으로 바꾼다.
- 움직이는 도식은 `slides/scenes.js`에 `ShowMe.scene('#대상', { init, enter, leave })`로 쓴다.
- `slides/engine/`은 고치지 않는다. 엔진에 필요한 것이 생기면 `제작노트.md`의 "엔진 후보"에 적는다.
- 공개 범위가 걸린 화면(고객·동료·가족)이 든 덱은 게시하지 않는다. `media.json`의 `share: onsite-only`가 그 목록이다.

## 설계 이유

- **빌드 없이 index.html이 정본인 이유.** 처음 사례(2026-11-25 강의 덱 v2)는 예전 덱 HTML의 줄 번호를 잘라 붙여 빌드했다. 다음 강의에서 그 줄 번호를 알아야 재사용할 수 있었다. 두 번째 사례도 독립적으로 같은 결론(빌드 없음, 엔진과 내용 분리)에 이르렀다.
- **엔진을 덱마다 복사하는 이유.** 발표 컴퓨터에서 `slides/` 폴더 하나만 열면 되어야 한다. 덱은 만들 때의 엔진으로 계속 같은 모습을 낸다. 엔진 갱신은 요청할 때만, 수정 전 촬영본과 비교해서 한다.
- **영상 skill을 복사하지 않는 이유.** Lightplay의 범위는 영상이다. 슬라이드만 필요한 사람에게 영상 도구 전체를 설치시키지 않는다. 두 하네스는 Lightplay가 op55를 쓰는 것처럼 파일 계약으로만 잇는다.
- **찍은 화면으로 판정하는 이유.** HTML과 종료 코드는 글자가 무대 밖으로 나가거나 장면 스크립트가 오류를 내도 정상으로 보인다. 반대로 휑한 장이나 어색한 문장은 사람 눈에만 걸린다. 그래서 자동 검사, 에이전트가 시트를 본 기록, 사람의 리허설을 나눠 보고한다.

자세한 결정과 미확인 항목은 [DESIGN](../../DESIGN.md)에 있다.
