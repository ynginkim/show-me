# Third-party provenance and licensing scope

The repository's original contributions are MIT. This does not relicense third-party code, externally installed packages, fonts, images, or quoted texts.

## Engine origin

The deck engine (`skills/resolve-show-me-tools/assets/engine/`) and the starter layout parts were extracted from the repository owner's own 2026-11-25 lecture deck. That deck's content (screens, recordings, documents) is not included. Only neutral, generated sample media appear in `examples/`.

## Playwright

`skills/resolve-show-me-tools/scripts/package.json` declares `playwright-core` (`^1.64.1`). Playwright is an external installed dependency under [Apache-2.0](https://github.com/microsoft/playwright/blob/main/LICENSE), not original MIT code from this repository. `node_modules/` is not committed. Preserve the license and notices shipped with the installed version when redistributing it. The system Chrome browser used for screenshots has its own terms.

## Fonts

No font files are bundled. `new_deck.py` copies or downloads [Pretendard](https://github.com/orioncactus/pretendard) (variable, via jsdelivr `pretendard@1.3.9`) and [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) (`v2.304`), both under the SIL Open Font License 1.1, into each deck's `slides/fonts/`. Keep their licenses with decks you redistribute. Fonts you add to a deck need their own license records.

## Lightplay

Lightplay is a separate skillset with its own license and [third-party notices](https://github.com/ynginkim/lightplay/blob/main/THIRD_PARTY.md). show-me only reads files a Lightplay project already produced. Videos, audio, fonts, and images copied from a Lightplay project keep their original sources and terms, which are recorded in that project's production notes.

## Deck media

Recordings, captures, and images converted into a deck are the user's material. `media.json` records each file's source path and SHA256 and whether it is `onsite-only`. This repository's license does not apply to them.

## Sample media

`examples/sample-deck/slides/media/` was generated by `examples/sample-deck/make_media.py` (Pillow drawings and ffmpeg test tones). It is original MIT material and contains no real person, product, or document.

`assets/lightplay-banner.jpg` is a resized copy of the README banner of the separate [Lightplay](https://github.com/ynginkim/lightplay) repository by the same owner, used to introduce that project. Its provenance and terms are recorded in Lightplay's README and `THIRD_PARTY.md`.
